# AGENTS.md

Навчальний вебзастосунок на Next.js для практичних робіт курсу «Агентна інженерія».

## Стек
- Середовище: Node.js >= 24, менеджер пакетів — npm (використання yarn/pnpm заборонено).

## Команди
- `npm test` — тести (Vitest), без мережі.
- `npm run typecheck` — перевірка типів, без емісії.
- Перед звітом «готово» обов'язково запустити перевірки та показати вивід.

## Межі
- `.env` і `.env.local` агент не читає і не редагує: секрети веде людина.
- Дії лише з дозволу людини: `git push`, створення комітів, видалення файлів.

## Домовленості
- Формат комітів: Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).
