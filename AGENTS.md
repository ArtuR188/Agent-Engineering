# AGENTS.md

Навчальний вебзастосунок на Next.js для практичних робіт курсу «Агентна інженерія».

## Стек

- TypeScript (`strict`), Next.js (App Router), Vitest.
- Середовище: Node.js >= 24, менеджер пакетів — npm (використання yarn/pnpm заборонено).

## Команди

- `npm test` — тести (Vitest), без мережі.
- `npm run typecheck` — перевірка типів, без емісії.
- `npm run lint` — лінтер.
- `npm run build` — тестова збірка (Next.js Turbopack).
- Перед звітом «готово» обов'язково запустити `npm test`, `npm run typecheck`, `npm run lint` та надати вивід. Усі мають бути зеленими.

## Межі

- `.env` і `.env.local` агент не читає і не редагує: секрети веде людина.
- Тести не ходять у мережу і не викликають платні API.
- `package-lock.json` вручну не змінювати, оновлення тільки через `npm install`.
- `.agent-log/` — лише додавання нових записів, старі не модифікувати і не видаляти.
- Дії лише з дозволу людини: `git push`, редагування `package.json`, видалення файлів чи даних, витрати понад ліміт.

## Домовленості

- Модель обирається роллю з `src/models.ts` (`MODELS.cheap`), а не рядком-ідентифікатором.
- Ціни й дати зняття моделей звіряються зі сторінкою вендора, а не з пам'яті.
- Якщо падає тест: спочатку пояснити причину багу в коді; заборонено змінювати тест під помилку.
- Формат комітів: Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).
- Мова відповідей та коментарів у коді — українська.
