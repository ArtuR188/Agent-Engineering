# Гібридний пошук і цитування

## 1. З чого складається
- Індекс: `data/index.json`, ембедер `google:gemini-embedding-001@768`, **36** фрагментів (крок 04)
- Гілка змісту: `cosineSimilarity` з `ai`, топ-**20** (`DEPTH = 20`)
- Гілка слів: своя реалізація BM25 (`src/rag/bm25.ts`), `k1 = 1.2`, `b = 0.75`, топ-**20**; токенізація: `/[\p{L}\p{N}]+/gu` із фільтром `t.length > 1`; стемінгу немає
- Злиття: RRF (`src/rag/rrf.ts`), `score = Σ 1/(60 + rank)`, ранги з `1`, відсутній документ додає `0`
- На вихід: топ-**5**
- Вектор запиту: той самий ембедер (`google:gemini-embedding-001@768`, 768 вимірів), `taskType: 'RETRIEVAL_QUERY'` (документи індексувалися з `RETRIEVAL_DOCUMENT`)

## 2. Формат цитати
`[doc-04#0001] doc-04 › Коди помилок турнікетів та RFID-браслетів (серія T-100..T-500) › 1. Помилки вхідної групи та зчитувачів браслетів (T-100..T-299) · символи 66–887`
- Зсуви `0`-based, у **НОРМАЛІЗОВАНОМУ** тексті документа (`normalize()` з `src/rag/chunk.ts`, крок 04)
- Як читач знаходить місце за 10 секунд: відкриває файл `corpus/<docId>.md` (або `docs/lab2/corpus/<docId>.md`), переходить до шляху заголовків `heading` та перевіряє зріз `text.slice(start, end)` за 0-based індексами
- Перевірка: `validateAnswer(answer, served)` перевіряє наявність хоча б одного `[doc-XX#NNNN]` та відсутність цитат на невидані фрагменти; `validateCitations(citations, served)` перевіряє дослівне входження `quote` у `chunk.text`

## 4. Правило відмови (теги `unanswerable`)
- Порогом **НЕ** є бал RRF (він залежить лише від рангів `1/(60 + rank)` і для топ-1 завжди близький до `1/61 ≈ 0.01639`)
- Критерій (`shouldRefuse` у `src/rag/search.ts`): `maxCosine < MIN_COSINE_THRESHOLD`, де `MIN_COSINE_THRESHOLD = 0.71`
- Як відкалібровано: перевірено на всіх 20 запитах `docs/lab2/golden/queries.jsonl`. Для 4 запитів `unanswerable` (`q-15` басейн `0.6748`, `q-16` коктейлі `0.6462`, `q-17` паркінг `0.6498`, `q-18` масаж `0.6655`) максимальний косинус лежить у межах `0.6462–0.6748`, тоді як для всіх 16 запитів із відповіддю (`q-01`.. `q-14`, `q-19`.. `q-20`) максимальний косинус становить `0.7444–0.8530`. Поріг `0.71` відсікає 4/4 `unanswerable` без хибних відмов на запитах із колекції.
