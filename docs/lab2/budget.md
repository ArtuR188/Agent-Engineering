## 1. Граф залежностей
| Частина роботи | Читає | Пише | Потрібен на вході результат | Паралельна з |
|---|---|---|---|---|
| Прогін запиту набору | `data/index.json`, `queries.jsonl` | — (результат у памʼять) | готовий індекс | з іншими запитами набору |
| Запис `parallel-run.json` | пам'ять пулу | `docs/lab2/parallel-run.json` | результати всіх паралельних гілок пулу | ні з чим |

Справді незалежні частини: прогін різних запитів з `queries.jsonl` (читання контексту та виклик LLM без збереження стану).
Здавалися незалежними, але не є: 
- Одночасні запити до Gemini API — через жорсткі ліміти пропускної здатності безкоштовного ключа запити стають у невидиму чергу провайдера (сума часу гілок зросла втричі).
- Запис у загальний JSON — виконується виключно після завершення `Promise.all`, щоб уникнути конфліктів файлової системи.
Усе, що пише: запис `eval-run.json` / `parallel-run.json` — виконується по одному.

## 2. Бюджет (записано ДО запуску)
- Максимум одночасних гілок: 4 — піднято з 1 до 4; ширше немає сенсу через throttling Gemini API на безкоштовному рівні.
- Стеля токенів на прогін: 200,000
- Стеля часу стіни: 600 с (10 хв)
- Правило зупинки: нову гілку не починати, якщо `spentTokens() >= budget.maxTokens || performance.now() - startedAt >= budget.maxWallMs`
- Межі агента кодування: CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS=4, CLAUDE_CODE_MAX_TOOL_USE_CONCURRENCY=4, CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1
- Стеля кроків агентного циклу: stopWhen: isStepCount(20)

## 4. Маршрутизація
| Частина роботи | Модель | Чому саме вона | Що буде з дешевшою | Пробували? |
|---|---|---|---|---|
| Евалюація RAG (генерація) | gemini-3.5-flash-lite | Масові читання, безкоштовний рівень API, достатня якість екстракції. | Дешевшої від Flash-Lite у Google API немає. | Так, це базовий рівень. |
| Аудит коду / План SaaS | Claude 3.5 Sonnet | Потребує глибокого логічного мислення та координації графів коду (AST). | Дешева модель зіб'ється на середині контексту або не втримає структуру JSON. | Так, на базових кроках. |

Дані, які НЕ можна віддавати на безкоштовний рівень: персональні дані клієнтів залу, медичні виписки травм, реальні P&L бізнесу → маршрут: Ollama локально.
Причина: на безкоштовному рівні вміст використовується для покращення продуктів Google.

## 5. Ізоляція записів
- Спосіб: git worktree вручну.
- Перевірка основного дерева після прогону: `git -C . status --short` → порожньо (тільки згенеровані метрики).
- Відома межа: перевірки worktree не стежать, куди пише команда оболонки, тому перевірка робиться вручну після кожного прогону.

## 6. Висновок
Паралельність при ширині 4 майже не окупилася: час стіни скоротився лише на 22% (з 77.8 с до 60 с), але сумарний час роботи гілок зріс майже втричі (з 77.8 с до 223 с). Оскільки кількість токенів залишилась ідентичною, це прямий наслідок жорсткого ліміту (throttling) на пропускну здатність безкоштовного API Gemini. Використання пулу вище 2–4 гілок без платного ключа недоцільне.
