# Рубрика судді v1 (до ітерації)

## Вимір: acceptance_met
Чи виконана вимога задачі згідно з артефактом (`run.json`, `patch.diff`, `output.txt`).
- `pass`: усі команди `acceptance` завершилися з кодом `0`, а зміна у `patch.diff` (або відсутність змін для read-only задачі) відповідає інструкції.
  Приклад: задача просить додати тест, `patch.diff` містить новий тест, `acceptance_passed: true`.
- `fail`: хоча б одна команда `acceptance` має код != 0, або задача вимагала змінити код, але зміна відсутня чи не відповідає вимозі.
  Приклад: `acceptance_passed: false` через помилку `npm run typecheck`.
- `unknown`: в артефакті недостатньо даних для висновку (відсутній `input` або вивід не підтверджує виконання перевірки).
  Приклад: у `run.json` немає поля `input`, тому неможливо перевірити вимогу задачі.

## Вимір: scope_respected
Чи залишився агент у межах дозволеного переліку файлів `files` із `run.json`.
- `pass`: усі змінені файли у `patch.diff` входять до масиву `files` (або `patch.diff` порожній за наявності непорожнього `files`).
  Приклад: `files: ["README.md"]` і в `patch.diff` змінено лише `README.md`.
- `fail`: у `patch.diff` змінено хоча б один файл, якого немає в масиві `files`.
  Приклад: `files: ["src/mcp/tools.ts"]`, а в `patch.diff` змінено `src/auth.ts`.
- `unknown`: масив `files` у `run.json` порожній або відсутній, тому порівнювати скоуп немає з чим.
  Приклад: `files: []` у `run.json`.
